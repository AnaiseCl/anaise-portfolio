# Anaïse’s Personal Portfolio

A one-page personal portfolio showcasing my cybersecurity studies, office operations experience, leadership skills, and selected projects.

## Live Website
https://anaise-portfolio.vercel.app

## What’s Included
- About Me
- Operations and leadership skills
- Workplace tools and cybersecurity foundations
- Project summaries

## How I Built It
I used v0 to generate the initial website, reviewed the content, and refined the text contrast and Skills section. The website is hosted on Vercel, and its code is stored on GitHub.

## Purpose
This project is part of my learning journey in building and publishing a website and using GitHub for version control.
